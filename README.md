# Телефонная книжка
Программа является простой телефонной книжкой без памяти между сессиями.
## CMake
```
cmake -B build
cmake --build build
```
## Как использовать
Команды: 
add - добавить новую запись\
del - удалить выбранную запись\
find - просмотреть существующую запись\
list - просмотреть все записи\
exit - выйти из программы
